# WIGEVO

Um jogo de luta simples desenvolvido em **linguagem C**, criado para praticar conceitos básicos de programação, estruturas, funções e ponteiros.

## 🎮 Sobre o jogo

**Wigevo** é um jogo de luta onde o jogador pode criar seu próprio lutador, definindo seu nome e seus atributos de **vida, ataque e defesa**.

Depois da criação dos personagens, os lutadores participam de uma batalha, utilizando seus atributos para determinar o resultado dos ataques.

O projeto foi desenvolvido como uma forma de praticar programação em C e aplicar os conceitos aprendidos durante os estudos.

## 🛠️ Tecnologia utilizada

* C

## 📚 Conceitos praticados

* `struct`
* Funções
* Ponteiros
* `if / else`
* `do while`
* `scanf` e `printf`
* Variáveis e operadores
* Manipulação de atributos de uma `struct`

## ⚔️ Como funciona

1. O jogador cria o personagem.
2. Define o nome do lutador.
3. Define os atributos de vida, ataque e defesa.
4. Os personagens participam da batalha.
5. Os ataques reduzem a vida do adversário.
6. O lutador que ficar sem vida perde a batalha.

## 🎯 Objetivo

O objetivo do projeto é desenvolver um jogo simples enquanto pratico os fundamentos da linguagem C, principalmente o uso de `struct`, funções e ponteiros.
